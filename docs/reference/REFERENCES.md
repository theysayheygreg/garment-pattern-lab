# References

This file is the project bibliography. Keep links here and write interpretation in nearby reference docs.

## Patternmaking Fundamentals

- Pattern Drafting and Grading for Basic Patterns. ResearchGate. Covers measurements, pattern terms, basic skirt/bodice/sleeve blocks, grading rules.  
  https://www.researchgate.net/publication/368816976_PATTERN_DRAFTING_AND_GRADING_FOR_BASIC_PATTERNS

- Design your own clothes: flat pattern method. University of Minnesota Conservancy. Public PDF.  
  https://conservancy.umn.edu/items/3a20dfe4-7397-404b-a55c-f12465b26d48

- Principles of Flat Pattern Design, Nora M. MacDonald. Bloomsbury/Fairchild. Standard flat-pattern textbook.  
  https://www.bloomsbury.com/uk/principles-of-flat-pattern-design-4th-edition-9781628920208/

- The principles of pattern making, public-domain/archival PDF. Wikimedia Commons.  
  https://commons.wikimedia.org/wiki/File%3AThe_principles_of_pattern_making%2C_written_specially_for_apprentices_and_students_in_technical_schools_%28IA_principlesofpatt00horn%29.pdf

- Patternmaking for Fashion Design, Helen Joseph Armstrong. Standard fashion-school reference. Commercial/copyrighted; cite for awareness, do not ingest without a lawful source.

## Commercial Garment Software

- Lectra Modaris. Patternmaking, grading, 3D prototyping, 2D/3D sync, pattern conversion.  
  https://www.lectra.com/en/fashion/products/modaris

- Optitex 2D/3D CAD Pattern Design Software. 2D pattern design, 3D visualization, avatar editor, tension maps, fabric management.  
  https://optitex.com/products/2d-and-3d-cad-software/

- Optitex 3D Overview. Notes that creating 3D cloth begins from real flat patterns plus style sheet, materials, model measurements.  
  https://help.optitex.com/1382687/Content/Optitex_3D/3D_Overview.htm

- Browzwear / VStitcher. 3D apparel design and virtual twins.  
  https://browzwear.com/

- CLO Simulation docs. Simulation sews seamlines between garment patterns and drapes them on avatars.  
  https://support.clo3d.com/hc/en-us/articles/115000304968-Simulation

- Gerber AccuMark 2D/3D release overview.  
  https://www.iafnet.com/2019/11/18/gerber-new-accumark-2d-3d-release/

- Wild Ginger Software. Custom-sized sewing patterns and professional pattern software.  
  https://www.wildginger.com/

## Open Source / Free Pattern Tools

- Seamly2D. Free/open-source pattern drafting CAD.  
  https://seamly.io/

- Seamly2D GitHub.  
  https://github.com/FashionFreedom/Seamly2D

- FreeSewing. Open-source made-to-measure pattern generation.  
  https://freesewing.org/

- FreeSewing About. Describes parametric designs and measurements.  
  https://freesewing.org/docs/about/

- PatternSoft. Free/open-source desktop app combining FreeSewing, pattern repository, visual drawing/grading, SVG/PDF export.  
  https://patternsoft.drytrix.com/

- Valentina. Open-source pattern drafting software.  
  https://valentina-oficial.b-cdn.net/index.html

- Tau Meta. Open-source sewing-pattern software project using SVG/Inkscape ideas.  
  https://www.taumeta.org/

## UV Unwrapping / 3D Modeling

  https://docs.blender.org/manual/id/4.0/modeling/meshes/editing/uv.html

- Blender UV docs index. UV maps, seams, unwrap, packing, stitching, export UV layout.  
  https://docs.blender.org/manual/en/latest/modeling/meshes/uv/index.html

- Maya Auto Seams. Automatic seam selection for UV unwrapping.  
  https://help.autodesk.com/view/MAYACRE/ENU/?guid=GUID-461CA58E-E485-4F0F-AE45-1DE077C664AB

  https://dev.epicgames.com/documentation/es-mx/unreal-engine/using-uv-channels-with-static-meshes-in-unreal-engine

## Research: Sketch / 3D / Pattern Generation

- Computational Pattern Making from 3D Garment Models. Segments 3D garment shapes into patches and computes 2D parameterizations for cut-and-sew patterns.  
  https://arxiv.org/abs/2202.10272

- GarmentCode: Programming Parametric Sewing Patterns.  
  https://arxiv.org/abs/2306.03642

- GarmentCodeData: A Dataset of 3D Made-to-Measure Garments With Sewing Patterns. 115,000 data points, 3D garments and corresponding sewing patterns, open-source draping pipeline.  
  https://arxiv.org/abs/2405.17609

- GarmentCodeData project page.  
  https://igl.ethz.ch/projects/GarmentCodeData/

- Sketch2Cloth: Sketch-based 3D Garment Generation with Unsigned Distance Fields.  
  https://arxiv.org/abs/2303.00167

- SketchTailor: Lightweight sketch-driven modeling for high-fidelity garment pattern reconstruction. Computers & Graphics, 2025.  
  https://www.sciencedirect.com/science/article/abs/pii/S0097849325001864

- GarmentDiffusion: 3D Garment Sewing Pattern Generation with Multimodal Diffusion Transformers.  
  https://arxiv.org/abs/2504.21476

- GenPattern: dual-graph enhanced sewing pattern generation via multimodal large language model. Journal of Manufacturing Systems, 2025.  
  https://www.sciencedirect.com/science/article/pii/S0278612525002663

- GarmentImage: Raster Encoding of Garment Sewing Patterns with Diverse Topologies.  
  https://arxiv.org/abs/2505.02592

- Deep Fashion3D: A Dataset and Benchmark for 3D Garment Reconstruction from Single Images.  
  https://arxiv.org/abs/2003.12753

- Adobe Research: Parsing Sewing Patterns into 3D Garments. SIGGRAPH 2013.  
  https://research.adobe.com/publication/parsing-sewing-patterns-into-3d-garments/

- GARSKETCH3D: sketch-based 3D apparel product modelling platform. Early sketch-to-3D-to-pattern concept.  
  https://research.manchester.ac.uk/en/publications/garsketch3d-a-sketch-based-3d-apparel-product-modelling-platform/

- Parametric 3D clothing generation: From sketch to dynamic fit. Published online 2026-04-28. Sketch plus body parameters to 3D garment geometry, but it appears to bypass explicit production pattern output.  
  https://journals.sagepub.com/doi/full/10.1177/15589250261441600
