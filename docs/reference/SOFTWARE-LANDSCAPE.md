# Software Landscape

## Commercial Pattern / Apparel CAD

### Lectra Modaris

Strengths:

- Production patternmaking.
- Grading.
- 3D prototype verification.
- 2D/3D synchronization.
- Pattern conversion.

Lesson:

- Industrial software treats pattern quality, grading, and production metadata as first-class.

### Optitex

Strengths:

- 2D pattern design.
- 3D visualization.
- Avatar editor.
- Fabric management.
- Tension map.
- Marker/nesting.

Lesson:

- 3D cloth starts from flat patterns plus style/design information, materials, and model measurements.

### Browzwear / VStitcher

Strengths:

- Accurate virtual twins.
- Fabric measurements.
- 3D apparel development workflow.
- Collaboration and review.

Lesson:

- The market values fewer physical samples, but the production workflow still relies on expert control.

### CLO

Strengths:

- Widely used 3D garment simulation and visualization.
- Strong design iteration surface.

Lesson:

- Good for styling and virtual samples, but professional production quality still depends on pattern skill.

## Open / Free Tools

### FreeSewing

Open-source parametric made-to-measure pattern generation.

Potential use:

- Reference for measurement-driven pattern generation.
- Possible library or schema inspiration.

Risk:

- Existing designs may not map cleanly to arbitrary sketch-derived topology.

### Seamly2D / Valentina

Open-source pattern drafting CAD.

Potential use:

- File format and drafting concepts.
- Patternmaker-facing workflow study.

Risk:

- May be better as an interoperability target than core engine.

### GarmentCode

Research tool for programmable parametric sewing patterns.

Potential use:

- Strong candidate for representation inspiration.
- Useful for synthetic data and pattern grammar thinking.

Risk:

- Need to verify licensing, installation, maturity, and whether it handles the first target garment cleanly.

### PatternSoft

New open-source desktop app combining FreeSewing, local pattern repository, visual drawing/grading, SVG/PDF export.

Potential use:

- Product reference for local-first pattern editing.
- Possible design inspiration for visual grading and repository surface.

## Product Gap

The gap is not "there is no pattern software."

The gap is:

**There is no broadly accessible system that translates a rough visual garment idea into a constrained, editable, validated sewing-pattern draft.**

Existing tools are powerful once the user knows patternmaking. This project should make the first draft easier without pretending expertise is unnecessary.
