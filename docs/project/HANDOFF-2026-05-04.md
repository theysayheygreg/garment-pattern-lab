Takeaways:

- Real imperial home-print patterns commonly use a 1 inch scale square.
- Real package conventions include tiled pages, page numbers, alignment marks, match points, size/layer lines, fold labels, cut counts, fabric direction, facings, closures, and optional component variants.
- The Bow Back Knit Top is a knit/child-size/top reference. Do not turn the A-line woven tunic into that garment. Use it to harden package conventions and future feature modules.
