# Garments

Garment-specific programs, fixtures, references, and outputs.

Each garment folder should use reusable packages from `packages/` rather than embedding product engine logic.

First target:

- `a-line-dress-tunic/`

Benchmark scaffolds:

- `classic-woven-shirt/`
- `camp-shirt/`
- `tank-with-facing/`
- `shift-dress-with-darts/`
- `sleeveless-top-with-facing/`

Future garment programs can add different drafting rules and validation expectations without changing the app shell.
