# A-Line Dress / Tunic

First prototype garment program.

Scope:

- adult sleeveless A-line woven dress/tunic
- front/back body panels
- loose pullover first
- optional bust dart/back opening later
- neckline and armhole binding/facing notes
- human-readable SVG/PDF package
- simple 3D preview

Subfolders:

- `docs/`: garment-specific drafting and construction notes.
- `fixtures/`: measurements, parameters, sketches, landmarks, expected pattern JSON.
- `references/`: allowed metadata and notes for same-family examples.
- `outputs/`: generated prototype packages.
