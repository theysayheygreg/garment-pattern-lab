# Sketch Fixtures

Generated and human-authored sketch fixtures for the sleeveless A-line woven dress/tunic.

Expected future contents:

- source images or links
- prompt provenance for generated examples
- landmark JSON
- semantic callout JSON
- ambiguity reports
- input manifests recording lane, rights/privacy note, view relationship, scale state, and semantic review status

`input-manifest.schema.json` is the v0.1 admission checklist for sketch inputs. Before a Kiko/human/generated input can count toward Phase C closure, it needs known provenance, a front/back or single-side relationship, an honest scale state, and a semantic review note.
